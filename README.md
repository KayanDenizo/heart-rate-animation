# 💖 Heart Rate Animation

Animação de linha de batimento cardíaco feita só com HTML e CSS.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## Como rodar

Não precisa instalar nada: basta abrir o arquivo `heart-animation/index.html` no navegador (ou usar a extensão **Live Server** do VS Code).
